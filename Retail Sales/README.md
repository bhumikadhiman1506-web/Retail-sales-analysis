# 🛍️ Retail Sales Analysis

## 📌 Project Overview
This project focuses on analyzing retail sales data using Python to identify sales trend, compare product category performance, and understand customer patterns.

The anaylsis helps extract meaningful insights from the dataset using data analysis and visualization technique.

## Tools & Libraries Used

• 🐍 Python

• 🐼 Pandas

• 📊 Matplotlib

## Dataset 
The dataset contains retail transaction information, including:

• 🧾 Transaction ID

• 👤 Customer ID

• 🚻 Gender

• 🎂 Age

• 🛒 Product Category

• 📦 Quantity

• 💰 Price per Unit

• 💵 Total Amount

• 📅 Date

## Analysis Performed 

• Explored the dataset using basic Pandas functions.

• Checked data types, missing values, and duplicate records.

• Analyzed sales performance across product categories.

• Compared total quantity sold with total sales amount by product category.

• Analyzed monthly sales trends.

• Compared total sales amount by gender.

• Created charts using Matplotlib to visualize sales patterns.

## 💡Key Findings

• Electronics generated the highest total sales amount among the product categories.

• Clothing ranked second, followed by Beauty, in total sales amount.

• Monthly sales analysis helped identify months with higher and lower sales.

• Sales comparisons by gender provided insights into customer purchasing patterns.

## 💻 Skills Demonstrated

• Data Cleaning and Exploration

• Data Aggregation and Grouping

• Data Analysis using Pandas

• Numerical Analysis using NumPy

• Data Visualization using Matplotlib

• Interpreting Business Insights

# 🚀 How to Run the Project

1. Clone or download this repository.
2. Install the required libraries:
    pip install pandas matplotlib

3. Keep the dataset CSV file in the same folder as the Python script.

4. Run the Python file:
    python retail_sales_analysis.py
